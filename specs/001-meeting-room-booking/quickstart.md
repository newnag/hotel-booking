# Quickstart Guide: Hotel Meeting Room Booking System

**Feature**: 001-meeting-room-booking  
**Last Updated**: 2025-11-11

## Purpose

This guide provides step-by-step instructions for setting up and running the hotel meeting room booking system locally for development and testing.

## Prerequisites

Ensure you have the following installed:

- **PHP**: Version 8.2 or higher
- **Composer**: PHP dependency manager
- **Node.js**: Version 18.x or higher
- **NPM**: Version 9.x or higher
- **MySQL**: Version 8.0 or higher
- **Git**: Version control system
- **Web Server**: Apache or Nginx (or use Laravel's built-in server)

### Recommended Development Environment

- **Laravel Homestead**: Pre-packaged Vagrant box with all dependencies
- **Laravel Valet** (macOS): Lightweight development environment
- **Docker**: Using Laravel Sail for containerized development
- **XAMPP/WAMP**: For Windows users

## Step 1: Clone Repository

```bash
git clone <repository-url> hotel-booking
cd hotel-booking
git checkout 001-meeting-room-booking
```

## Step 2: Install PHP Dependencies

```bash
composer install
```

This installs Laravel and all required PHP packages including:
- Laravel Framework 12.x
- Line Messaging API SDK
- PHPUnit for testing
- Laravel Debugbar (development)
- Laravel Telescope (development)

## Step 3: Install JavaScript Dependencies

```bash
npm install
```

This installs:
- Vite (asset bundler)
- Bootstrap 5
- AdminLTE 3
- FullCalendar.js
- Axios (HTTP client)
- Other frontend dependencies

## Step 4: Environment Configuration

### Create Environment File

```bash
cp .env.example .env
```

### Generate Application Key

```bash
php artisan key:generate
```

### Configure Database

Edit `.env` file with your MySQL credentials:

```env
APP_NAME="Hotel Meeting Room Booking"
APP_ENV=local
APP_KEY=base64:...  # Generated by previous command
APP_DEBUG=true
APP_URL=http://localhost:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=hotel_booking
DB_USERNAME=root
DB_PASSWORD=your_password

# Session & Cache
SESSION_DRIVER=database
CACHE_DRIVER=file
QUEUE_CONNECTION=database

# Mail Configuration (for password reset)
MAIL_MAILER=smtp
MAIL_HOST=mailhog  # Or your SMTP server
MAIL_PORT=1025
MAIL_USERNAME=null
MAIL_PASSWORD=null
MAIL_ENCRYPTION=null
MAIL_FROM_ADDRESS="noreply@hotel-booking.local"
MAIL_FROM_NAME="${APP_NAME}"

# Line Messaging API
LINE_CHANNEL_ACCESS_TOKEN=your_line_channel_access_token
LINE_CHANNEL_SECRET=your_line_channel_secret

# Optional: Telescope (development only)
TELESCOPE_ENABLED=true
```

### Line API Setup (Optional for testing)

1. Create a Line Messaging API channel at https://developers.line.biz/
2. Get your Channel Access Token and Channel Secret
3. Add them to `.env` file
4. For local testing, you can leave these empty and notifications will be logged instead

## Step 5: Create Database

### Using MySQL CLI

```bash
mysql -u root -p
```

```sql
CREATE DATABASE hotel_booking CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;
```

### Or using phpMyAdmin

1. Open phpMyAdmin
2. Click "New"
3. Database name: `hotel_booking`
4. Collation: `utf8mb4_unicode_ci`
5. Click "Create"

## Step 6: Run Database Migrations

```bash
php artisan migrate
```

This creates all database tables:
- users
- meeting_rooms
- decoration_themes
- room_themes (pivot)
- bookings
- line_notifications
- password_resets
- failed_jobs
- sessions

## Step 7: Seed Database with Sample Data

```bash
php artisan db:seed
```

This creates:
- Admin user (email: admin@hotel.com, password: password)
- Staff user (email: staff@hotel.com, password: password)
- Guest user (email: guest@hotel.com, password: password)
- 5 meeting rooms with different capacities
- 6 decoration themes
- Sample bookings for demonstration

## Step 8: Create Storage Link

```bash
php artisan storage:link
```

This creates a symbolic link from `public/storage` to `storage/app/public` for file uploads (theme preview images).

## Step 9: Compile Frontend Assets

### For Development (with hot reload)

```bash
npm run dev
```

Keep this running in a separate terminal for automatic asset recompilation.

### For Production Build

```bash
npm run build
```

## Step 10: Start Development Server

```bash
php artisan serve
```

The application will be available at: **http://localhost:8000**

## Step 11: Start Queue Worker (for Line Notifications)

In a new terminal window:

```bash
php artisan queue:work
```

This processes queued jobs for sending Line notifications asynchronously.

## Troubleshooting

### Issue: Migration Fails

**Solution**: Ensure MySQL is running and credentials in `.env` are correct

```bash
# Test connection
php artisan tinker
>>> DB::connection()->getPdo();
```

### Issue: Assets Not Loading

**Solution**: Ensure npm build is running

```bash
npm run dev
```

And storage link is created:

```bash
php artisan storage:link
```

### Issue: Queue Jobs Not Processing

**Solution**: Ensure queue worker is running

```bash
php artisan queue:work
```

For development, you can use sync queue driver in `.env`:

```env
QUEUE_CONNECTION=sync
```

### Issue: Permissions Error

**Solution**: Set proper permissions on storage and cache directories

```bash
# Linux/Mac
chmod -R 775 storage bootstrap/cache

# Or
sudo chown -R www-data:www-data storage bootstrap/cache
```

### Issue: Line Notifications Not Sending

**Solution**: 

1. Check queue worker is running
2. Verify Line API credentials in `.env`
3. Check notification logs:

```bash
php artisan tinker
>>> \App\Models\LineNotification::latest()->get();
```

4. For local development, use log driver:

```env
LINE_CHANNEL_ACCESS_TOKEN=
LINE_CHANNEL_SECRET=
```

Notifications will be logged to `storage/logs/laravel.log`
